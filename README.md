# text-to-sql-agent

A tool-using agent that answers plain-English questions about a SQL database, written directly on
the Claude Messages API with no agent framework, and an evaluation harness that measures it on the
BIRD Mini-Dev benchmark (500 questions, 11 real databases).

The agent is the small part. Most of this repo is about measuring it honestly: a fixed benchmark,
an ablation where each configuration changes one thing, confidence intervals on every number,
paired significance tests between configurations, cost and latency per question, and hand-labelled
failure analysis.

> **Status (Oct 16, 2026):** harness, agent, tests and CI are done; model runs start Oct 17.
> The results table below is generated by `make report` and is empty until then.

## How the agent works

```mermaid
flowchart LR
    Q[Question + hint] --> M[Claude]
    M -->|list_tables / describe_table / sample_rows| T[Read-only SQLite]
    M -->|run_sql: test a query| T
    T -->|rows or error text| M
    M -->|submit_answer| S[Scorer]
    S -->|compare with cached gold rows| R[results.jsonl]
```

One step is one model call. The model can look at the schema, read the dataset's column notes,
look at real rows, test queries, and see its own errors. It ends by calling `submit_answer`. The
loop also stops on a step cap (12), a token budget or an API failure, and every run records which
of these happened.

## Findings so far (from the harness, before any model runs)

- **The ceiling is 99.6 to 99.8%, not 100%, and it depends on the machine.** Two gold queries are slow
  on SQLite: question 701 took 325s and question 518 took 62s when run alone. With a 60s limit on
  predicted queries, 701 always times out, and 518 passes or fails depending on machine load. Two
  oracle runs on the same machine scored 99.6% and 99.8%. A time limit in the scorer makes the
  score depend on hardware, which is worth knowing before comparing numbers across machines.
- **The two dataset releases differ.** The 2024 package has 498 questions; the July 2025 Hugging Face
  release has 500, and two shared questions have different gold SQL. Results here use the 2025
  release (decision [0001](docs/decisions/0001-benchmark.md)).
- **Column notes were silently lost.** Several of BIRD's column-description CSVs have a trailing comma
  in the header row, so the value notes the agent needs most (for example, that `POPLATEK MESICNE`
  means monthly issuance) end up in an unnamed column. A plain CSV reader drops them without an
  error. `data.py` folds them back in, and a test covers it.

## Design choices

Each has a short decision record in [docs/decisions](docs/decisions/README.md).

- **Read-only by construction.** The database connection is opened with `mode=ro`, so SQLite itself
  refuses writes. sqlglot parses each query first only to give the agent a clear error message.
  A test runs `DELETE` with the parser check turned off to show the connection still refuses.
- **Scoring matches BIRD's official rule** (`set(pred_rows) == set(gold_rows)`), so the numbers are
  comparable with published results. The rule's blind spots are pinned by tests and listed in
  [0004](docs/decisions/0004-scoring.md). Gold results are computed once and cached.
- **Uncertainty is reported.** Bootstrap 95% intervals on every accuracy, seeded question samples
  so strategies see the same questions, and an exact McNemar test for each pair.
- **Cost is tracked per question,** from the API's token counts including prompt-cache reads and
  writes. Prices live in `pricing.py`, so old runs can be re-priced.
- **Two runners, one code path.** The `sqlagent` CLI is resumable and does paired comparisons. An
  [Inspect AI](https://inspect.aisi.org.uk/) task runs the same agent and scorer and gives
  structured logs and a transcript viewer.

## Quickstart

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/).

```bash
make install                 # dependencies, dev tools, git hooks
make data                    # BIRD Mini-Dev (800 MB download), checksum check, gold cache
cp .env.example .env         # then add ANTHROPIC_API_KEY

make oracle                  # harness check, no API key needed, expect 99.6 to 99.8%
make smoke                   # agent on 20 questions
uv run sqlagent run --strategy agent --limit 100 --model claude-haiku-5-5
uv run sqlagent compare runs/<run A> runs/<run B>
uv run sqlagent show runs/<run> <question_id>     # full trace of one question
uv run sqlagent failures runs/<run>               # CSV of wrong answers to label

uv run inspect eval evals/bird_inspect.py --model mockllm/model -T strategy=agent -T limit=20
uv run inspect view
```

## Limitations

- One benchmark, SQLite only. Results may not carry over to other databases or SQL dialects.
- BIRD's scoring ignores row order and duplicates and can count a coincidental match as correct.
- Model outputs are not deterministic. The plan includes repeated runs to measure the spread.
- Some BIRD gold labels are known to contain errors. A corrected 2026 release exists and is future work.
